# 🐴 EquinoPlay 

> **Juego móvil interactivo diseñado para apoyar sesiones de equinoterapia en niños.**  
> Desarrollado en Kotlin para Android como proyecto de asignatura optativa.

---

## 📌 Sobre el Proyecto

**EquinoPlay** es un juego para dispositivos móviles (Android) pensado para acompañar, motivar y potenciar las sesiones de **equinoterapia** (terapia asistida con caballos) en niños. 

A través de dinámicas lúdicas, mecánicas simples y estímulos visuales/sonoros adaptados, el juego busca:
- **Estimular habilidades motrices y cognitivas:** Coordinación, memoria, atención y seguimiento de instrucciones.
- **Generar un vínculo positivo con la terapia:** Familiarizar a los niños con los caballos, el equipamiento (montura, cascos, riendas) y la rutina del centro ecuestre.
- **Herramienta de apoyo terapéutico:** Servir como recurso educativo antes, durante o después de las sesiones en pista.

---

## 💡 Características Principales

- 🎨 **Interfaz amigable e intuitiva:** Diseñada con colores atractivos, botones grandes y tipografías legibles para facilitar la accesibilidad.
- 🐴 **Temática enfocada en equinoterapia:** Personajes, animales y entornos ecuestres.
- 🎮 **Mini-juegos educativos:** *(Ajusta según lo que tenga tu app)*
  - Alimentar y cuidar al caballo (reconocimiento de elementos).
  - Rompecabezas y asociación de formas/colores.
  - Juegos de memoria y secuencia de movimientos.
- 🔊 **Feedback sonoro y visual positivo:** Refuerzo constante para incentivar los logros sin frustración.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** [Kotlin](https://kotlinlang.org/)
- **Plataforma:** Android (SDK mínimo recomendado: Android 8.0 / API 26+)
- **Entorno de desarrollo (IDE):** Android Studio
- **Librerías principales:**
  - *Android Jetpack / Jetpack Compose* (o XML / ViewBinding según corresponda)
  - *Coroutines* (para manejo de tareas asíncronas)
  - *Glide / Coil* (para la carga eficiente de imágenes y gifs)
